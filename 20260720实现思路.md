# 20260720 在线推理与 PD 分离实现思路

这份文档整理两部分内容：

- 在线推理应该如何对齐 vLLM / Mooncake 的设计
- 在当前 `nanovllm_self` / `pd_self` 代码基础上，在线化之前应该先做哪些前置改进

当前重点不是马上接 HTTP server，而是先把 engine 内部改成更适合在线推理的结构。

---

## 1. vLLM 在线推理怎么做

vLLM 的在线推理可以理解成：

```text
API Server
  -> AsyncLLMEngine.add_request()
  -> 后台 engine loop 持续 step()
      -> scheduler.schedule()
      -> model_executor / model_runner.forward()
      -> sampler / output processor
      -> stream token 给客户端
```

核心点：

- `LLMEngine` 负责 input processing、scheduling、model execution、output processing
- `AsyncLLMEngine` 负责在线请求接入、后台循环、异步输出
- scheduler 每个 step 动态选择本轮处理哪些 request
- online serving 不是一次 `generate()` 跑完，而是常驻 engine loop 持续执行

vLLM 的典型 step 语义：

```text
1. 优先处理 running decode 请求
2. 再处理 running prefill chunk
3. 再从 waiting 队列接纳新 prefill
4. postprocess 后返回新 token
5. finished 请求释放 KV block
```

## 2. Mooncake 在线 PD 思路

Mooncake 更强调 KVCache-centric：

```text
Gateway / Router
  -> Prefill Cluster
      -> 生成 prompt KV
      -> 把 KV 放进 disaggregated KV cache pool
  -> Decode Cluster
      -> 取回 KV
      -> 继续 decode
      -> stream 输出
```

Mooncake 的重点不是简单拆两个进程，而是：

- 把 KV cache 当作第一类资源
- prefill / decode cluster 分离
- 通过 KV transfer backend 传递上下文状态
- router 根据 SLO、负载和 KV 命中做调度

你当前 `pd_self` 已经有接近这个方向的原型：

```text
PrefillEngine
DecodeEngine
HandoffPayload
KVConnector
SharedMemoryKVStoreBackend
```

还缺的是：

```text
常驻 worker loop
异步 request queue
handoff queue
step-level streaming
异常清理和生命周期管理
```

## 3. 当前代码和在线系统的映射

### 3.1 单体推理链路

当前 `llm_engine_self.generate()` 大致是：

```text
token ids -> Sequence
  -> scheduler.add(seq)
  -> while scheduler not finished:
      scheduled = scheduler.schedule()
      token_ids, need_logits = model_runner.run(scheduled)
      scheduler.postprocess(scheduled, token_ids, need_logits)
```

对应在线 engine：

```text
add_request()        -> scheduler.add(seq)
step()               -> schedule + model_runner.run + postprocess
request state table  -> request_id -> seq/output/status
stream queue         -> 每步 token 输出
```

### 3.2 PD 推理链路

当前 `PDCoordinator.generate()` 是同步链路：

```text
PrefillEngine.run_prefill()
  -> KVConnector.save_kv()
  -> HandoffPayload
DecodeEngine.run_decode(payloads)
  -> KVConnector.load_kv()
  -> decode until finished
```

对应在线 PD：

```text
PrefillWorkerLoop
  -> drain prefill_queue
  -> prefill_step()
  -> handoff ready 后放入 handoff_queue

DecodeWorkerLoop
  -> drain handoff_queue
  -> restore_sequence(payload)
  -> decode_step()
  -> 每步 stream token
```

## 4. 在线化之前必须先做的前置改进

### P0-1：修复 PD prefill 侧 block 生命周期

位置：

- `pd_self/prefill_engine.py`

当前 handoff ready 后只是：

```python
if seq in self.scheduler.running:
    self.scheduler.running.remove(seq)

payloads[seq.seq_idx] = self._make_payload(seq, finished=False)
handed_off.add(seq.seq_idx)
```

问题：

```text
prefill 侧 block 没有释放。
离线小测试问题不大，但在线服务会导致 prefill runner 的 KV cache 越来越满。
```

建议语义：

```text
1. save_kv(seq)
2. 生成 payload
3. 从 running 移除 seq
4. 释放 prefill 侧 block
```

样例：

```python
if self._is_handoff_ready(seq):
    payload = self._make_payload(seq, finished=False)

    if seq in self.scheduler.running:
        self.scheduler.running.remove(seq)

    self.model_runner.block_manager.deallocate(seq)

    payloads[seq.seq_idx] = payload
    handed_off.add(seq.seq_idx)
```

注意：

```text
必须先 make payload / save_kv，再 deallocate。
因为 save_kv 需要从 prefill runner.kv_cache 里导出 KV。
```

### P0-3：scheduler 改成 decode-first

位置：

- `nanovllm/engine/scheduler.py`

当前逻辑：

```text
按 running 队列顺序推进
running 里可能既有 prefill，也有 decode
然后再接 waiting
```

在线服务更推荐：

```text
1. decode first
2. running prefill chunk
3. waiting new prefill
```

原因：

```text
decode 影响 ITL / TPOT
prefill 影响 TTFT
在线服务通常优先保护已经开始 decode 的请求
```

样例：

```python
def schedule(self):
    scheduled_decode = []
    scheduled_prefill = []
    scheduled_new = []
    token_budget = self.max_num_batched_tokens
    num_seqs = 0

    # 1. decode first
    for seq in list(self.running):
        if token_budget <= 0 or num_seqs >= self.max_num_seqs:
            break
        if not seq.is_prefill_done:
            continue

        if not self.block_manager.can_append(seq):
            continue

        self.block_manager.may_append(seq)
        seq.num_new_tokens = 1
        seq.status = SequenceStatus.RUNNING
        scheduled_decode.append(seq)
        token_budget -= 1
        num_seqs += 1

    # 2. running prefill chunks
    for seq in list(self.running):
        if token_budget <= 0 or num_seqs >= self.max_num_seqs:
            break
        if seq.is_prefill_done:
            continue

        remaining = len(seq) - seq.num_cached_tokens
        num_new_tokens = min(remaining, token_budget)
        if self.config.enable_chunked_prefill:
            num_new_tokens = min(num_new_tokens, self.config.prefill_chunk_size)

        if num_new_tokens <= 0:
            continue

        seq.num_new_tokens = num_new_tokens
        seq.status = SequenceStatus.RUNNING
        scheduled_prefill.append(seq)
        token_budget -= num_new_tokens
        num_seqs += 1

    # 3. new prefill admission
    while self.waiting and token_budget > 0 and num_seqs < self.max_num_seqs:
        seq = self.waiting[0]

        if not seq.block_table:
            if not self.block_manager.can_allocate(seq):
                break
            self.block_manager.allocate(seq)

        remaining = len(seq) - seq.num_cached_tokens
        num_new_tokens = min(remaining, token_budget)
        if self.config.enable_chunked_prefill:
            num_new_tokens = min(num_new_tokens, self.config.prefill_chunk_size)

        if num_new_tokens <= 0:
            break

        seq.num_new_tokens = num_new_tokens
        seq.status = SequenceStatus.RUNNING
        self.waiting.popleft()
        self.running.append(seq)
        scheduled_new.append(seq)

        token_budget -= num_new_tokens
        num_seqs += 1

    return scheduled_decode + scheduled_prefill + scheduled_new
```

这只是调度策略样例，不一定直接替换现有实现。

### P0-6：PrefillEngine 拆成 add_request + step

位置：

- `pd_self/prefill_engine.py`

当前：

```python
def run_prefill(...):
    build seqs
    scheduler.add(seq)
    while len(handed_off) < total:
        scheduled = scheduler.schedule()
        model_runner.run(...)
        scheduler.postprocess(...)
        if handoff_ready:
            payload = _make_payload(...)
```

在线 PD 需要：

```text
prefill worker 常驻
每轮 step 推进部分请求
handoff ready 后返回 payload
```

建议接口：

```python
def add_request(self, text, seq_idx, temperature, max_tokens, ignore_eos):
    seq = self._build_sequence(text, seq_idx, temperature, max_tokens, ignore_eos)
    self.scheduler.add(seq)
    return seq

def step(self):
    if self.scheduler.is_finished():
        return []

    scheduled = self.scheduler.schedule()
    if not scheduled:
        return []

    token_ids, need_logits = self.model_runner.run(scheduled)
    self.scheduler.postprocess(scheduled, token_ids, need_logits)

    payloads = []
    for seq in scheduled:
        if seq.status == SequenceStatus.FINISHED:
            payloads.append(self._make_payload(seq, finished=True))
            continue

        if self._is_handoff_ready(seq):
            payload = self._make_payload(seq, finished=False)
            if seq in self.scheduler.running:
                self.scheduler.running.remove(seq)
            self.model_runner.block_manager.deallocate(seq)
            payloads.append(payload)

    return payloads
```

位置：

- `nanovllm/engine/block_manager.py`

`can_allocate(seq)` 是按完整 prompt 分配：


## 6. 单体在线推理样例

目标：

```text
把 llm_engine_self.generate() 拆成 add_request + step + run_loop。
```

样例：

```python
import threading
import time
import uuid
from queue import Queue, Empty

from nanovllm.engine.Sequence import Sequence
from nanovllm.sampling_params import SamplingParams

class OnlineLLMEngine:
    def __init__(self, llm_engine):
        self.engine = llm_engine
        self.inbound_queue = Queue()
        self.requests = {}
        self.seq_to_request = {}
        self.running = False
        self.thread = None
        self.next_seq_idx = 0

    def add_request(self, text: str, sampling_params: SamplingParams):
        request_id = f"req-{uuid.uuid4().hex[:12]}"
        self.inbound_queue.put((request_id, text, sampling_params))
        return request_id

    def _drain_new_requests(self):
        while True:
            try:
                request_id, text, sampling_params = self.inbound_queue.get_nowait()
            except Empty:
                break

            token_ids = self.engine.tokenizer(text, add_special_tokens=False)["input_ids"]
            seq = Sequence(
                seq_idx=self.next_seq_idx,
                token_ids=token_ids,
                sampling_params=sampling_params,
                block_size=self.engine.config.block_size,
            )
            self.next_seq_idx += 1

            self.requests[request_id] = {
                "seq": seq,
                "tokens": [],
                "finished": False,
                "queue": Queue(),
            }
            self.seq_to_request[seq.seq_idx] = request_id
            self.engine.scheduler.add(seq)

    def step(self):
        self._drain_new_requests()

        if self.engine.scheduler.is_finished():
            time.sleep(0.001)
            return

        scheduled = self.engine.scheduler.schedule()
        if not scheduled:
            time.sleep(0.001)
            return

        token_ids, need_logits = self.engine.model_runner.run(scheduled)
        self.engine.scheduler.postprocess(scheduled, token_ids, need_logits)

        for local_idx, token_id in zip(need_logits, token_ids):
            seq = scheduled[local_idx]
            request_id = self.seq_to_request[seq.seq_idx]
            state = self.requests[request_id]
            state["tokens"].append(token_id)
            state["queue"].put(token_id)

            if seq.status.name == "FINISHED":
                state["finished"] = True
                state["queue"].put(None)

    def run_loop(self):
        self.running = True
        while self.running:
            self.step()

    def start(self):
        self.thread = threading.Thread(target=self.run_loop, daemon=True)
        self.thread.start()

    def stop(self):
        self.running = False
        if self.thread is not None:
            self.thread.join()

    def get_result(self, request_id):
        return self.requests[request_id]["tokens"]

    def get_stream_queue(self, request_id):
        return self.requests[request_id]["queue"]
```

## 7. 在线 PD 样例

更贴近 Mooncake / vLLM disaggregated prefill 的形态：

```text
PrefillWorker:
  inbound_queue -> scheduler -> handoff_queue

DecodeWorker:
  handoff_queue -> restore_sequence -> scheduler -> output_queue
```

### 7.1 OnlinePrefillWorker 样例

```python
from queue import Queue, Empty

class OnlinePrefillWorker:
    def __init__(self, prefill_engine, handoff_queue):
        self.engine = prefill_engine
        self.handoff_queue = handoff_queue
        self.inbound_queue = Queue()
        self.active = {}
        self.next_seq_idx = 0

    def add_request(self, request_id, text, temperature, max_tokens, ignore_eos):
        self.inbound_queue.put((request_id, text, temperature, max_tokens, ignore_eos))

    def _drain_new_requests(self):
        while True:
            try:
                request_id, text, temperature, max_tokens, ignore_eos = self.inbound_queue.get_nowait()
            except Empty:
                break

            seq = self.engine._build_sequence(
                text=text,
                seq_idx=self.next_seq_idx,
                temperature=temperature,
                max_tokens=max_tokens,
                ignore_eos=ignore_eos,
            )
            self.next_seq_idx += 1
            self.active[seq.seq_idx] = request_id
            self.engine.scheduler.add(seq)

    def step(self):
        self._drain_new_requests()

        if self.engine.scheduler.is_finished():
            return

        scheduled = self.engine.scheduler.schedule()
        if not scheduled:
            return

        token_ids, need_logits = self.engine.model_runner.run(scheduled)
        self.engine.scheduler.postprocess(scheduled, token_ids, need_logits)

        for seq in scheduled:
            if seq.status.name == "FINISHED":
                request_id = self.active.pop(seq.seq_idx)
                payload = self.engine._make_payload(seq, finished=True)
                self.handoff_queue.put((request_id, payload))
                continue

            if self.engine._is_handoff_ready(seq):
                request_id = self.active.pop(seq.seq_idx)
                payload = self.engine._make_payload(seq, finished=False)

                if seq in self.engine.scheduler.running:
                    self.engine.scheduler.running.remove(seq)
                self.engine.model_runner.block_manager.deallocate(seq)

                self.handoff_queue.put((request_id, payload))
```

### 7.2 OnlineDecodeWorker 样例

```python
from queue import Empty

class OnlineDecodeWorker:
    def __init__(self, decode_engine, handoff_queue, request_table):
        self.engine = decode_engine
        self.handoff_queue = handoff_queue
        self.request_table = request_table
        self.seq_to_request = {}

    def _drain_handoff(self):
        while True:
            try:
                request_id, payload = self.handoff_queue.get_nowait()
            except Empty:
                break

            if payload.finished:
                req = self.request_table[request_id]
                for token_id in payload.token_ids[payload.num_prompt_tokens:]:
                    req.output_queue.put(token_id)
                req.output_queue.put(None)
                req.finished = True
                continue

            seq = self.engine.restore_sequence(payload)
            self.seq_to_request[seq.seq_idx] = request_id
            self.engine.scheduler.running.append(seq)

    def step(self):
        self._drain_handoff()

        if self.engine.scheduler.is_finished():
            return

        scheduled = self.engine.scheduler.schedule()
        if not scheduled:
            return

        token_ids, need_logits = self.engine.model_runner.run(scheduled)
        self.engine.scheduler.postprocess(scheduled, token_ids, need_logits)

        for local_idx, token_id in zip(need_logits, token_ids):
            seq = scheduled[local_idx]
            request_id = self.seq_to_request[seq.seq_idx]
            req = self.request_table[request_id]
            req.output_queue.put(token_id)

            if seq.status.name == "FINISHED":
                req.finished = True
                req.output_queue.put(None)
```

### 7.3 OnlinePDCoordinator 样例

```python
import threading
import uuid
from dataclasses import dataclass, field
from queue import Queue

@dataclass
class OnlinePDRequest:
    request_id: str
    text: str
    max_tokens: int
    temperature: float
    ignore_eos: bool
    output_queue: Queue = field(default_factory=Queue)
    finished: bool = False
    error: str | None = None

class OnlinePDCoordinator:
    def __init__(self, pd_coordinator):
        self.pd = pd_coordinator
        self.handoff_queue = Queue()
        self.requests = {}

        self.prefill_worker = OnlinePrefillWorker(
            self.pd.prefill_engine,
            self.handoff_queue,
        )
        self.decode_worker = OnlineDecodeWorker(
            self.pd.decode_engine,
            self.handoff_queue,
            self.requests,
        )

        self.running = False
        self.thread = None

    def add_request(self, text, max_tokens=64, temperature=0.0, ignore_eos=True):
        request_id = f"req-{uuid.uuid4().hex[:12]}"
        req = OnlinePDRequest(
            request_id=request_id,
            text=text,
            max_tokens=max_tokens,
            temperature=temperature,
            ignore_eos=ignore_eos,
        )
        self.requests[request_id] = req
        self.prefill_worker.add_request(
            request_id=request_id,
            text=text,
            temperature=temperature,
            max_tokens=max_tokens,
            ignore_eos=ignore_eos,
        )
        return request_id

    def step(self):
        self.prefill_worker.step()
        self.decode_worker.step()

    def run_loop(self):
        self.running = True
        while self.running:
            self.step()

    def start(self):
        self.thread = threading.Thread(target=self.run_loop, daemon=True)
        self.thread.start()

    def stop(self):
        self.running = False
        if self.thread is not None:
            self.thread.join()

    def stream(self, request_id):
        q = self.requests[request_id].output_queue
        while True:
            item = q.get()
            if item is None:
                break
            yield item
```

## 8. 推荐推进顺序

建议按下面顺序推进：

1. 修复 PD prefill handoff 后 block 释放
2. 让 scheduler 支持空调度返回
3. 改 scheduler 为 decode-first / prefill-chunk / waiting-admission
4. 开启 chunked prefill 的在线默认策略
5. 把 DecodeEngine 拆成 `restore_payloads + step + run_until_finished`
6. 把 PrefillEngine 拆成 `add_request + step + run_until_handoff`
7. 补 KVConnector 异常清理和 `delete_by_ref`
8. 增加 RequestState / request_id 映射
9. 增加 cancel / timeout / exception 释放路径
10. 最后接 OnlineLLMEngine / OnlinePDCoordinator
11. 再接 HTTP / SSE / WebSocket

## 9. 一句话总结

在线化不是先接 FastAPI，而是先把内部推理循环改成：

```text
request queue + scheduler.step + model_runner.run + token streaming + cleanup
```

PD 在线化不是简单把 `generate()` 放进线程，而是改成：

```text
PrefillWorker 常驻 + DecodeWorker 常驻 + handoff queue + KVConnector 异步化
```

你当前已有的 `Scheduler`、`ModelRunner.prepare_model_input()`、`KVConnector`、`SharedMemoryKVStoreBackend` 都可以继续作为基础，但在线化之前必须先收敛 block 生命周期、空调度、decode-first 和 step 化接口。
